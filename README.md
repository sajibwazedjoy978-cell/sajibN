## 📱 Android-Friendly Guide: How to Publish on GitHub Pages for FREE

You can publish this website directly from your **Android phone** (using Chrome browser) or a computer in 5 simple steps:

### Step 1: Open GitHub
1. Open Google Chrome on your phone or computer and visit [github.com](https://github.com).
2. Log in (or create a free account if you don't have one).
3. If using Chrome on Android, tap the three dots in the top right and check **"Desktop site"** for easier navigation.

### Step 2: Create a New Repository
1. Tap the green **"New"** button (or the **+** icon in the top bar -> **New repository**).
2. Repository name:
   - For a personal domain address like `username.github.io`, name the repository:  
     `sajibnofficial.github.io` (replace with your GitHub username).
   - Or name it `personal-website` or `portfolio`.
3. Set visibility to **Public**.
4. Check **"Add a README file"** and tap **"Create repository"**.

### Step 3: Upload the Files
1. Inside your new repository, tap **"Add file"** -> **"Upload files"**.
2. Upload the following files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `favicon.svg`
   - `robots.txt`
   - `sitemap.xml`
   - Create folder `assets/images/` and upload `profile.jpg` inside it.
3. Scroll down and tap **"Commit changes"**.

### Step 4: Enable GitHub Pages
1. In your repository, tap the **"Settings"** tab (gear icon).
2. On the left sidebar, tap **"Pages"**.
3. Under **"Build and deployment"** -> **"Source"**, select **"Deploy from a branch"**.
4. Under **"Branch"**, choose `main` (or `master`) and folder `/ (root)`, then tap **"Save"**.

### Step 5: Live Website Ready!
- Wait approximately 60 seconds.
- Refresh the Pages tab. GitHub will display:
  > **"Your site is live at `https://yourusername.github.io/`"**
- You now have an official personal brand website with free HTTPS!
